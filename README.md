# .dotfiles
Automate all the things

## Usage
Clone the git into your HOME, so the repo is in `~/.dotfiles`.
Then run `bootstrap_osx.sh` from the project root.

TPM plugins need a manual install, use `prefix + I`

## Shell keybindings

fzf and McFly are lazy-loaded on first use (faster startup).

| Key | Tool |
|-----|------|
| Ctrl+R | McFly (history search) |
| Alt+R | fzf (history search) |
| Ctrl+T | fzf (files) |
| Alt+C | fzf (directories) |
